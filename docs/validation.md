# 回放尖塔实机验收

## 复现环境

Windows x64，.NET 9，游戏主分支 `0.111.1 / cc1f9462` 和测试分支 `0.113.1 / d09d48e5`。游戏安装提供本地引用程序集与资源。测试工具使用私有副本、独立用户目录、关闭 Steam 集成，普通场景设为静音。声音专项测试将游戏输出定向到 Steam Streaming Speakers 虚拟设备。

```powershell
dotnet run --project tests/Storage/StorageTests.csproj -c Release
python scripts/acceptance.py 'D:/Games/Slay the Spire 2' --name review --ffmpeg 'C:/Tools/ffmpeg.exe' --campaign
```

`--ffmpeg` 启用视频专项，包括有声、静音、取消、清晰度和同步；`--campaign` 额外跑三幕路线。在另一版本的本地游戏目录执行同一命令，会写入独立的版本子目录。每次完整验收使用新的会话名。原始日志、私有回放和哈希记录在 `.local/<会话>/<游戏版本>/`。

## 实测样本

主分支的三幕测试走完 48 层，游戏登记为胜利。原生战斗重播检验 30 场战斗的 228 个状态校验点，同时覆盖跨幕地图和最终建筑师事件。在进入第一层之前，测试脚本为铁甲战士设置了 1,000 点生命和强化牌组，随后按地图实际连接行进。该路线用于复现跨幕、结局和存储负担。五角色测试使用各角色的原版起始牌组。

| 记录样本 | 房间记录 | 本地记录目录 | 便携文件 |
| --- | ---: | ---: | ---: |
| 一次主分支三幕胜利 | 52 段，含 30 场战斗 | 4,325,359 字节 | 859,110 字节 |
| 一场两回合战斗 | 含地图入口和战斗 | 96,788 字节 | 21,119 字节 |

三幕样本同时保留原始记录和自动导出文件，共约 4.94 MiB。每场战斗的回合数、选择次数、随模组加入的状态，以及中途读档次数都会改变体积。普通对局记录只写动作、房间入口和游戏原生校验数据。显存读回、声音采集和视频编码均在玩家启动导出时启用。

## 核显与独显

使用主分支安装包、同一台 i9-14900HX 笔记本、32 GB 内存，分别指定 Intel UHD 核显与 RTX 4070 Laptop 独显。每块显卡做两组开关录制的配对测试，第二组交换顺序。实际读回的画面均为 1280×720，游戏目标为 60 帧，所有样本的前台时间占比均为 100%。同一种子走相同的四个操作，核对最终手牌、敌人和玩家状态。

| 战斗样本 | 关闭录制时 P95 帧时间 | 开启录制时 P95 帧时间 | 开启录制时游戏进程工作集峰值 |
| --- | ---: | ---: | ---: |
| Intel UHD Graphics | 17.26 ms | 16.85 ms | 2.13–2.16 GiB |
| RTX 4070 Laptop GPU | 17.12 ms | 17.00 ms | 1.36–1.42 GiB |

帧时间取各轮 P95 的配对均值。这台机器的短战斗中，开启记录后的 P95 处在相近水平。核显与独显共享同一颗高性能 CPU。更慢的 CPU、8 GB 内存和其他模组组合仍需要在对应设备上测量。表中的内存是整个游戏进程的工作集。

另在 Intel UHD 上测量单次编码的 720p 导出。9.6 秒的文件为 1,723,670 字节，临时目录中只出现该 MP4。导出前游戏工作集为 2.17 GiB，导出中游戏和 FFmpeg 的合计峰值为 2.55 GiB。288 个输出帧中有 14 个复用前一帧。配置较低的机器可以先照常打牌，之后再按需要开一次导出。

## 如何核对

| 链路 | 核对内容 |
| --- | --- |
| 战斗录制与回放 | 实际出牌、抽洗牌、药水、嵌套选牌、随机目标、敌方回合和同一战斗的原生校验点 |
| 非战斗房间 | 房间入口、事件选项、营地休息、商店购买、开宝箱、战后金币和卡牌、地图落点 |
| 保存与分享 | 继续游戏后同一楼层的不同访问，独立用户目录导入同一文件两次，播放前后比较正式存档、原生回放、备份与历史的哈希 |
| 回放库 | 从卡牌、时间线、楼层选择器定位，暂停、逐手播放、跳回合，打开记录目录，生成实机图集和直播贴 |
| 有声 MP4 | 解码两条媒体流，核对帧尺寸、时间戳与音量，用三次闪光和同进程测试音测同步，并用另一个进程的声音测试隔离 |
| 录制负担 | 同一角色、同一种子与同一组输入交替开启、关闭记录，比较实际帧时间分位、内存、记录字节以及最终战斗状态 |

绘制、声音和录制性能以实际完成的对照样本为准。成片编码 H.264/AAC。每个验收阶段在单独的游戏进程执行，原生实测必须能找到阶段成功标记。验收脚本可通过 `--validator` 接入完整日志验证器。

## 人工验收

1. 自己打一场熟悉的单人战斗。在一个容易记住的节点停顿几秒。回主菜单打开回放，找到这个动作，检查节奏、暂停和跳转手感。
2. 在全局卡牌统计中选一张常用卡，查看详情并从记录回到现场。试一下键盘、手柄或常用显示比例。
3. 导出一段有声 MP4，听一次抽牌、命中或结束回合。打开整局直播贴目录，按文件名顺序选择截图，读一遍配文。以你愿意实际分享的效果作为验收标准。

`scripts/review.ps1 -GameVersion 0.111.1 -Session review` 可打开已经准备好的隔离实机环境。
